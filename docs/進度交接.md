## 工作方式和坑

從 `portfolio-main` 啟動，不要從上層目錄：

```sh
node --env-file-if-exists=.env server.js
```

http://localhost:3000 ，後台 http://localhost:3000/admin/ 。沒有 `.env`，不要新建，也不要發明密碼。`requireAuth` 直接 `next()`，所以沒密碼也能進後台。伺服器仍會印 `ADMIN_PASSWORD is not set`。`POST /api/login` 在沒密碼時會 500。

`getContent()` 把 `content.json` 留在記憶體。改檔之後要重開伺服器，前台才看得到。後台按 Save 會更新這份快取。

靜態檔快取用 query：

- `admin/index.html`：`admin.css?v=cache13`、`admin.js?v=cache16`
- `views/partials/head.ejs`：`style.css?v=cache20`
- `views/partials/footer.ejs`：`site.js?v=cache20`

改了這些檔要加版本號。

驗證前台要用瀏覽器點、滾、開關，不要只看一張截圖。量滾動時先把 `documentElement.style.scrollBehavior` 設成 `auto`。`Emulation.setDeviceMetricsOverride` 用完要在同一輪清掉。後台剛開時 snapshot 可能只看到登入標題，等 `startApp()` 畫完再看。`#app` 和 `#login` 一開始都是 hidden。

格子高度：`container-type: inline-size` 在外層 `.works-cells-wrap` / `.work-board-wrap`。不要放在用 `100cqw` 算列高的 grid 自己身上，否則列會變成整頁那麼高。不要用 `grid-auto-flow: dense`。

`admin.js` 的 `h()` 會跳過值是 `false` 的屬性。圖片要另外 `img.draggable = false`，不然拖卡片會變成拖圖片。

`cloneLayers` 只換最外層 id，group 的子層 id 沒換。物件有深拷貝。先不要為了這個改，除非使用者碰到。

不要改 `portfolio-main-old-20261028-182208`。後台存過的 layout 名稱裡有一個不該複述的詞，對使用者說話時不要寫出那個名字。
