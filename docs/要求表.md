# 作品集要求表

前台是一條長頁。後台仍是給自己和開源使用者用的 canvas 模板系統。這份表只記已經定下來的行為。

參考：

- 作品牆：三欄格子，每張有封面、編號、分類、年份、標題、短介紹、View Project
- 作品 popup：左欄文字、右欄往下捲看成品（PFL 那種）
- 左欄分段：一條線、一個標題、一段文字
- 間距與字級可參考 `D:\abbie114514\download\portfolio-case-demo-silvercord\portfolio-case-demo-silvercord\index.html`
- 新前台的外觀用 Galaxy、Impeccable、Hallmark。後台編輯器介面不動

## 1. 整站

| ID | 要求 |
| --- | --- |
| S1 | 訪客看到的是一條長頁。上面的 tab 跟著滾動位置亮起 |
| S2 | 你的站只有四個 tab：Home、Works、About、Contact |
| S3 | 開源使用者仍可在後台加更多段、套 canvas 模板。你的站只是用這套後台做出的一個作品集 |
| S4 | 模板套到某一段之後是獨立複本。再改這一段，不改模板原檔，也不改其他段 |
| S5 | 別人 clone 之後，只在後台就能換內容、套模板、排自己的站 |

## 2. Home

| ID | 要求 |
| --- | --- |
| H1 | Home 繼續用現在的 canvas |
| H2 | 已經存過的畫板維持現在的背景色 |
| H3 | 之後新建的 canvas，背景預設透明，透出頁面本身的顏色 |

## 3. Works 格子

| ID | 要求 |
| --- | --- |
| W1 | Works 這一段本身不是自由 canvas |
| W2 | 最小單位是一格。一列最多三欄 |
| W3 | 每個 block 可選 1×1、2×1（橫向佔兩欄、高度一列）、2×2 |
| W4 | 某個 block 若會在那一列留下空洞，就整塊換到下一列 |
| W5 | 後台可以拖動順序，並指定格子大小。不能把格子拖到任意座標 |
| W6 | 編號從 01 起，由左到右、由上到下，依排完的順序自動產生 |
| W7 | 每張作品卡顯示：封面、編號、分類、年份、標題、短介紹、View Project |
| W8 | 一個 block 也可以是圖片、文字、YouTube 或 PDF，但只能佔格子 |
| W9 | 點作品留在同一頁，打開 popup。關掉後回到剛剛的滾動位置 |

## 4. Feature

| ID | 要求 |
| --- | --- |
| F1 | Works 上方、tag 之上，橫向排三張 Feature |
| F2 | 每張卡自己的角落標著 Feature Work |
| F3 | 後台每份作品有 Feature 開關。最多三個。已經有三個時，要先關掉一個才能再選 |
| F4 | 點 Feature 開的是同一個作品 popup |
| F5 | 這三份在下面的格子裡還會再出現一次 |
| F6 | Feature 只在 All 時出現 |

## 5. Tag

| ID | 要求 |
| --- | --- |
| T1 | 作品牆上方有一排 tag。第一個是 All |
| T2 | 一個作品可以有多個 tag。popup 上的 tag 和這排是同一套 |
| T3 | 可以複選。作品只要有其中一個亮著的 tag 就出現 |
| T4 | 再點一次亮著的 tag 就取消 |
| T5 | 點 All 會關掉其他 tag，並顯示 Feature |
| T6 | 點任何分類會關掉 All，Feature 那一列收起來 |
| T7 | 全部分類都點掉時，回到 All，Feature 再出現 |
| T8 | 現有頁面收進 Works 時，用原來的頁名當 tag，標在該作品和裡面的素材上。例如 Character Design 那一頁的圖，帶 Character Design |

## 6. 作品 popup

| ID | 要求 |
| --- | --- |
| P1 | 作品介紹固定用左右兩欄，不用 canvas |
| P2 | 左欄必備：分類、標題、短介紹、tag |
| P3 | Role、Year、Output 有內容才顯示，沒填不留空卡 |
| P4 | 左欄預設三段。一段是一條分隔線、一個標題、一段文字。標題由使用者填 |
| P5 | 可以在段的前面、中間或最後插入新段，也可以像圖層一樣上下移動 |
| P6 | 一份 case 裡有多件成品。使用者指定一件當主視覺 |
| P7 | 主視覺同時是牆上的封面，也是右欄的第一件。其餘成品照使用者排的順序往下接 |
| P8 | 右欄的成品可以上下移動。主視覺在公開頁永遠排最上面 |
| P9 | 右欄從主視覺開始往下捲，看完這份作品的成品 |
| P10 | Silvercord 那頁只作文字和間距的參考，不規定一定要有 brief、process、outcome |

## 7. 舊頁與 canvas

| ID | 要求 |
| --- | --- |
| C1 | 現有頁（Artworks、Character Design 等）變成 Works 裡的作品。上面的 tab 不再各佔一個 |
| C2 | 這些頁原本的 canvas 留在後台，不刪 |
| C3 | 訪客的 popup 不再直接顯示舊 canvas |
| C4 | 不是作品介紹的 section，可以改用 canvas mode，自由放圖片、YouTube、PDF |
| C5 | 一段只選一種：格子，或 canvas。不在同一段裡混用 |

## 8. About

| ID | 要求 |
| --- | --- |
| A1 | About 是翻面名片，換掉現在的 About canvas |
| A2 | 這張名片只有你的站有，不進 canvas，也不進給別人用的模板庫 |
| A3 | 正面是自介、email 和社群連結 |
| A4 | 背面只有一支約 15 秒的 motion graphic。後台貼連結或上傳一個影片檔，翻過去就播放 |

## 9. Contact

| ID | 要求 |
| --- | --- |
| K1 | Contact 跟 Home 分開，在長頁上有自己的區域和 tab |
| K2 | 聯絡表單留在這一段 |

| ID | 要求 |
| --- | --- |
| D1 | 作品牆、popup、名片、Contact 的外觀用 Galaxy、Impeccable、Hallmark |
| D2 | 後台 canvas 編輯器的介面維持現在的樣子 |
